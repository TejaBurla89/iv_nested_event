# Monte Carlo Replication

This package reproduces Figure 3 in *Instrumental Variables in Nested Event Designs: Endogenous Exposure and Changes in Local Average Treatment Effects*.

## Data availability

The simulations use no external data. All observations are generated by the script from the data-generating processes summarized in the accompanying replication materials.

## Requirements

- Python 3.12
- NumPy 2.3
- pandas 2.2
- Matplotlib 3.10

Exact package versions are recorded in the release-level `requirements.txt`.

## Run

From the project root:

```bash
python simulation/figure3_monte_carlo.py
```

The fixed-seed run takes about 30 seconds on one CPU in the development environment. The script stops with an error if the main Monte Carlo means depart materially from their analytical population benchmarks.

## Outputs

- `figures/figure3_standardization_and_continuation.png`
- `figures/figure3_standardization_and_continuation.pdf`
- `results/standardization_summary.csv`
- `results/figure3_monte_carlo_metadata.json`

The script overwrites only these generated outputs. The plotted manuscript results use the same fixed-seed simulation outputs.
